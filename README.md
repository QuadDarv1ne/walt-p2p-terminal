# ⚡ walt-p2p-terminal

**Децентрализованный терминал для мониторинга P2P-рынка Walt.io** — веб-приложение,
которое целиком работает в браузере: без бэкенда, без базы данных, без аналитики.
Ключ API, избранное, алерты и история хранятся только на вашем устройстве.

Терминал читает официальный **P2P API Walt** (только чтение) и помогает находить
лучшие курсы, следить за спредом и рыночной матрицей. Сделки совершаются вручную
в интерфейсе [P2P Маркета Walt](https://walt.io/) — API не позволяет торговать.

---

## Возможности

| Блок | Что умеет |
| --- | --- |
| Лучшие курсы | покупка (мин. цена SELL-объявлений) и продажа (макс. цена BUY-объявлений), спред рынка, активность мейкеров |
| Объявления | таблица с сортировкой по цене/лимитам/рейтингу, пагинация, поиск, фильтр по сумме сделки (учёт `minAmount`/`maxAmount`), фильтр по способам оплаты, «только в сети», CSV-экспорт, копирование данных сделки |
| Мониторинг | график лучшего курса в реальном времени, избранное (до 8 пар), ценовые алерты (всплывающие + системные уведомления), калькулятор круговой сделки с комиссией |
| Матрица рынков | сводка по всем криптовалютам к выбранному фиату — клик открывает пару |
| Децентрализация | синхронизация вкладок через BroadcastChannel (лидер/последователь экономит запросы), прямая P2P-сеть между браузерами через WebRTC — обмен курсами, избранным и алертами без сервера |
| Автономность | PWA + Service Worker: после первой загрузки интерфейс работает офлайн; демо-режим для знакомства без ключа |

## Быстрый старт

### Вариант 1 — готовый статический дистрибутив (ничего не собирать)

В архиве есть папка `dist/` — полностью статическая сборка. Достаточно любого
статического сервера:

```bash
cd walt-p2p-terminal/dist
python3 -m http.server 8080
# откройте http://localhost:8080
```

Подходит и любой другой сервер (Nginx, `npx serve`, расширение Live Server и т.п.).
Открывать `index.html` двойным кликом (file://) не стоит — Service Worker и API-запросы
требуют http/https.

### Вариант 2 — сборка из исходников

Нужен [Bun](https://bun.sh) (или Node.js 20+):

```bash
bun install          # или npm install
bun run dev          # режим разработки на http://localhost:3000
bun run build        # продакшен-сборка standalone-сервера
bun run start        # запуск сервера
bun run build:static # статический экспорт в out/ (GitHub Pages, IPFS, …)
```

### Получение API-ключа

1. В главном меню Walt нажмите **«Пополнить»**.
2. Откройте **P2P Маркет → Мой профиль → API ключи → Создать API ключ**.
3. Укажите имя ключа и нажмите «Создать» (до 10 ключей на аккаунт).
4. Скопируйте ключ и вставьте его в настройках терминала (шестерёнка в шапке).

Ключ передаётся **только** в запросах к `p2p.walt.io` из вашего браузера.

## Режимы подключения

| Режим | Как работает |
| --- | --- |
| **Демо-данные** | симуляция рынка без ключа — для знакомства с интерфейсом |
| **Реальный API — напрямую** | браузер обращается к `p2p.walt.io` сам; работает, если API отдаёт CORS-заголовки |
| **Реальный API — через прокси** | список CORS-прокси (по одному в строке), запросы идут по списку до первого рабочего; шаблон `{url}` заменяется на адрес API |
| **Реальный API — через локальный релей** | запускаете `bun scripts/relay-proxy.ts` — он ходит в интернет (через VPN/прокси системы) и отдаёт данные браузеру с CORS-заголовками |

Если ни прямое подключение, ни прокси недоступны, терминал объяснит причину
(CORS, 401/403 — неверный ключ, 429 — слишком часто, 5xx — сбой API).

> ⚠️ **MTProto-прокси (ссылки `t.me/proxy?...`) не подходят.** Это транспортный протокол
> мессенджера Telegram — через него нельзя делать HTTP-запросы к `p2p.walt.io`.
> Для обхода блокировок используйте «через локальный релей» + VPN/прокси системы,
> или клиент вроде `mihomo` (Clash Meta) с upstream-прокси.

## Децентрализация

- **Синхронизация вкладок** — вкладки одного браузера договариваются напрямую
  через `BroadcastChannel`: пара, избранное и алерты зеркалятся, а запросы к API
  делает только вкладка-лидер.
- **P2P-сеть (WebRTC)** — два браузера соединяются напрямую по кодам приглашения
  (`WALT1:…`), пересланным любым мессенджером. Поверх канала участники обмениваются
  свежими курсами, избранным и алертами — например, можно видеть рынок даже без
  своего API-ключа. Сигналинг-сервер не нужен; STUN используется только для обхода NAT.
- **Хранение** — всё состояние в `localStorage`; экспорт/импорт состояния в JSON
  (ключ API в файл не выгружается).
- **Офлайн** — Service Worker кеширует оболочку приложения.

## Размещение (хостинг)

Статическая сборка (`bun run build:static` → папка `out/` или готовая `dist/`)
работает где угодно:

- **GitHub Pages** — загрузите содержимое `dist/` в ветку `gh-pages` (Settings → Pages);
- **Netlify / Vercel / Cloudflare Pages** — перетащите папку `dist/` в drag-and-drop;
- **IPFS** — `ipfs add -r dist/` или через Pinata/web3.storage; адрес пина можно
  расшарить напарникам для P2P-сети.

## Приватность и безопасность

- API-ключ хранится в `localStorage` вашего браузера и уходит только на `p2p.walt.io`
  (или на выбранный вами CORS-прокси — вводите только те адреса, которым доверяете).
- Нет телеметрии, аналитики и серверной части.
- P2P-обмен через WebRTC — данные идут напрямую между браузерами.

## Ограничения API

- P2P API Walt **только для чтения**: совершить сделку через API нельзя —
  терминал показывает рынок, а обмен проводится в интерфейсе Walt P2P Маркета.
- Данные рынка обновляются примерно раз в 30 секунд; интервал автообновления
  в терминале настраивается от 10 до 120 секунд.
